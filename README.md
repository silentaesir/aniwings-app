## What is AniWings?

**AniWings** is a modern anime streaming client designed for **Android phones, tablets, iOS (iPhone & iPad), Android TV, Google TV, Amazon Fire TV, NVIDIA Shield TV, Windows, and Linux**.

Discover anime, browse seasonal releases, follow airing schedules, manage your library, track episodes, use multiple providers, install provider extensions, download supported episodes, and watch through an interface designed specifically for mobile devices, televisions, and desktop computers.

> **No mandatory AniWings account. No intrusive advertising. Just anime.**

### Why AniWings?

- 🚫 **No Mandatory Sign-up** — Start browsing and watching without creating an AniWings account.
- 🎨 **Modern Interface** — A redesigned experience built for phones, tablets, televisions, and desktop computers.
- 🎬 **Multiple Providers** — Switch between available streaming sources when needed.
- 📖 **Manga & Light Novel Reader** — Read thousands of manga and light novels with offline download support on mobile (Android & iOS).
- 🎮 **Discord Rich Presence** — Showcase what you're watching on Discord in real time with quick and easy setup on Android, iOS, Windows, and Linux.
- 🔄 **Desktop Library Sync & Import/Export** — Sync with AniList and MyAnimeList via username or OAuth, and easily import/export watchlist data on Windows & Linux.
- 🔑 **TV Dual Sign-In** — Sign in smoothly using either Mobile ↔ TV QR Code Login or direct on-screen Manual Login.
- 🔌 **Extension Support** — Expand AniWings Mobile with additional provider extensions.
- ⬇️ **Offline Downloads** — Download supported episodes, manga chapters, and novel volumes for offline viewing.
- 📊 **Anime Tracking** — Support for AniList, MyAnimeList, Kitsu, and AniDB.
- 🍎 **iOS Support** — Dedicated `.ipa` build for iPhone and iPad.
- 📺 **Dedicated TV Experience** — TV-optimized layouts with full D-pad navigation.
- 🪟 **Windows Experience** — Native 64-bit client for Windows 10 & 11 with installer and zero-install portable formats.
- 🐧 **Linux Experience** — Universal AppImage with full hardware acceleration on Ubuntu, Debian, Fedora, and Arch.
- 🗣️ **SUB & DUB** — Access subtitled and dubbed sources where available.

# 🔌 Mobile Extension Support

> ### 📱 Available on AniWings Mobile (Android & iOS)

AniWings Mobile includes a modular **extension-based provider system** that allows users to expand the app with additional anime providers instead of relying entirely on the built-in servers.

### 🧩 Extension Manager

Install and manage supported provider extensions directly through AniWings.

Extensions can add their own:

- 🔍 Anime search
- 📚 Anime catalogs
- 📄 Anime information
- 🎞️ Episode lists
- 🎬 Streaming sources
- 🌐 Provider-specific functionality

### ⚡ How Extensions Work

Installed extensions operate separately from AniWings' built-in providers.

Once a compatible extension is installed, its supported sources can become available inside AniWings as additional provider options.

This gives the mobile app a more flexible architecture where additional compatible providers can be added without requiring every provider to be bundled directly into the main AniWings application.

### 🔧 Extension Features

- 🧩 **Install Extensions** — Add supported provider extensions from the Extension Manager.
- 📦 **Extension Management** — Manage installed provider extensions directly inside the app.
- 🔍 **Extension Search** — Search supported anime using installed extensions.
- 📺 **Additional Sources** — Extensions can provide additional episodes and playable sources.
- 🔄 **Independent Providers** — Extension providers work separately from built-in AniWings servers.
- ⚡ **Dynamic Provider Loading** — Installed extensions can appear as additional source options.
- 🛠️ **Expandable Architecture** — Additional compatible providers can be supported over time.
- 🌐 **Provider Flexibility** — Users aren't limited exclusively to AniWings' built-in server selection.

> **Note:** The Extension Manager is currently a **Mobile feature (Android & iOS)**. Extensions are not currently supported by the Android TV version. Availability and functionality can vary between individual extensions.

# 🔗 TV Sign-In: QR Code & Manual Login

AniWings for Android TV supports two convenient login methods:

### 1. 📱 QR Code Login (via AniWings Mobile)
1. Open AniWings on your TV and choose **QR Login**.
2. Open AniWings on your Android or iOS phone.
3. Scan the QR code displayed on your television screen.
4. Your account and watchlists will instantly synchronize to the TV!

### 2. ⌨️ Direct Manual Login (on TV)
1. Open AniWings on your TV and choose **Manual Login**.
2. Enter your username and password directly using your TV remote and the on-screen keyboard (or a connected keyboard).
3. Sign in immediately without needing a mobile device nearby.

# 🆘 Help & Support

Having trouble with AniWings?

Before reporting an issue:

1. Make sure you're using the **latest AniWings version**.
2. Try another available provider or server.
3. If you're using an extension, try another installed extension.
4. Check whether the problem happens with another anime or episode.
5. Restart AniWings.
6. If you're upgrading from an older incompatible build, uninstall the previous version and install the latest release.

### 🐛 Reporting Bugs

When reporting an issue, including the following information will make troubleshooting much easier:

```text
Device:
Operating System & Version:
AniWings Version:
Platform (Mobile / TV / Windows / Linux):
Anime:
Episode:
Provider / Extension:
Issue Description:
```

Please avoid including private account information, email addresses, passwords, or other sensitive information in public bug reports.
